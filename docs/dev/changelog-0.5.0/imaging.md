## Added

- `backproject(profile, aperture, pixels_m)`: time-domain back-projection of a range profile onto any pixel grid, returning a `SarImage`. FMCW (beat phasor, with the residual video phase), OFDM and pulsed phase laws; amplitude normalised so a point target images at its compressed amplitude. Differentiable with respect to the samples in both AD modes; a CUDA profile runs one native launch (`backprojection` family with an adjoint backward and a JVP), a CPU profile the same equation in Torch. Zero pad the range transform (`range_profile(range_bins=8 * N)`) before imaging.
- `Aperture`: each virtual element's position at each slow-time sample plus the waveform's phase law. `Aperture.from_radar(radar, time_s=..., velocity_mps=... | pose=...)` takes the TDM sample instants from the waveform and moves the array along a straight track or with the verbs' `pose(t)`; `Aperture.to(device)` keeps an image loop free of copies.
- `isar_aperture(aperture, center_m=..., angular_velocity_rad_s=... | rotation=...)`: the aperture in a turning target's body frame, so ISAR images are the same back-projection.
- `element_responses(profile, aperture, point_m)`: each virtual channel's phase-compensated response at one point.
- Calibration: `estimate_array_calibration` / `ArrayCalibration` (per-channel complex gain from a reflector at a known position, applied to a cube, range profile or Range-Doppler map), `estimate_range_calibration` / `RangeCalibration` (round-trip delay bias, applied by moving the range axis origin), `subtract_background` and `average_background` (leakage and static clutter removal against target-free reference frames).
