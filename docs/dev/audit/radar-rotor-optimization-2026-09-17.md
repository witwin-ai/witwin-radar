# 旋转目标完整场景调度优化验收（2026-09-17）

这次优化把原 MATLAB 对照中的完整旋转场景降至数百毫秒，同时保留原始物理模型、
采样参数、相位误差阈值及逐 ADC 参考。它没有证明任意重多径或移动网格也能在数百毫秒完成。

## 场景与测量方法

- witwin2；RTX 5080；Ryzen 7 9800X3D；Torch 2.10.0+cu128；Windows。
- 77 GHz、128 ADC × 1024 chirps、4 MHz 采样率、32 μs chirp、零 idle。
- 目标为沿半径 3 mm 圆周以 80 Hz 运动的点散射体，中心距离约 30 m；空世界 LOS。
  这是原比较的 orbital-point rotor，未改成已知路径输入，也不是一个完整旋转网格/叶片模型。
- 1 W 发射功率、1 m² RCS、单位天线增益；同一公共 `Radar.simulate` 调用。
- 自适应阈值仍为 0.02 rad、幅度相对误差 0.02、最大间隔 2 ms。
- 每组 1 次预热、3 次测量；计时前后 CUDA synchronize，包含发现、传播、组合、天线及 ADC 合成。
  不包含首次进程导入。共享桌面，未更改 GPU 时钟，也未终止用户程序。

## 最终性能与准确度

| 场景 | 中位耗时 | 实测范围 | 独立逐 ADC 公式的 IQ 相对 L2 误差 |
| --- | ---: | ---: | ---: |
| 原旋转场景，优化前 | 16.165 s | 14.870–19.294 s | 约 0.7207% |
| 同一旋转场景，优化后 | 608.7 ms | 571.8–818.5 ms | 0.7207% |
| 加速点目标 | 242.2 ms | 217.3–306.2 ms | 0.8132% |
| 两个关节运动散射点代理 | 519.9 ms | 442.9–599.3 ms | 0.5643% |
| 静态点，128 chirps | 19.46 ms | 18.16–19.55 ms | 0.0463% |

同一会话的旋转场景中位加速 **26.56×**；优化前后完整复数 IQ 的相对变化
**3.26435e-8**。独立参考在每个 ADC 时刻计算作者输入精度下的距离、双程相位与标量雷达方程。
它与 WiTwin 的剩余差异主要仍属于原来受控的时间插值和 float32 路径精度，而非本次调度近似。

先前第三阶段测得 497–586 ms、中位 566 ms；验收采用最后重复测量的 609 ms，未择优替换。
证据位于 `output/rotor-optimization/final/acceptance.json`；同目录保存所有完整 MAT 复数数据。

## 四项优化的具体结果

1. **路径重发现**：仅当世界无几何、传播为 LOS-only 且所有端点对都已发现时，证明候选族完整，
   复用冻结拓扑。677 次运动探针保留，发现次数从 677 降到 1。源变更、版本变化和句柄退休仍失效。
2. **小张量**：探针端点常量、ID、极化和功率复用；传播、双程组合和天线应用按时间批处理。
   所有发现行先打包一次，ADC 阶段按整数表 gather，删除逐 ADC 的 delay/clock/full_like 构造。
3. **拓扑策略**：反射世界仍在探针发现完整路径；身份或有效性变化继续细分至相邻 ADC。
   不能用“已有路径仍有效”来排除新路径。移动几何继续遵守 Channel 的重新编译/句柄生命周期。
4. **ADC 调度**：新增任意 ADC 时刻的 CSR 原生合成，共用 `fmcw_phase.cuh` 和现有 beat 相位函数。
   该旋转帧从 512 次合成调用降为 4 批。临时展开受观察数和 262144 行约束；单条更大观察不可拆。
   原生 VJP/JVP 同时实现；时间表/自适应离散选择不求导，延迟及复数权重保留一阶导数。

原有 169 个接受区间、677 个探针和最大已测相位残差 0.018469 rad 保持不变。
`batch_observations=256` 仍限制探针批；ADC 批最多为该值乘 ADC 样本数，并受行数上限限制。
默认 `motion_sampling="adc"` 没有更改。使用上述性能必须显式选择 `"adaptive"`。

## 重多径与 MATLAB 的边界

三面反射墙、每程 depth 2、64 条双程路径、32 chirps × 64 ADC 的完整实验：

- 逐 ADC 参考：96.321 s、2048 次发现。
- 自适应：1.356 s、37 次发现、1 次 ADC 合成批，约 71.0×。
- IQ 相对 L2 误差 0.0565946%；range-Doppler 功率相对 L2 误差 0.00648734%。

这是 WiTwin 对自己的穷举参考，不是 MATLAB 加速比。该重多径场景尚未达到数百毫秒。
它也不是旋转网格测试。真实移动网格的重编译以及一般反射几何的路径发现仍需要 Channel 支持进一步批处理。
当前 Channel 消费接口的 slot-major 批处理用于固定拓扑回放，不能拿它冒充批量拓扑发现。
逐时刻 `response.at(t)` 回调仍逐探针组合；本轮百毫秒证据采用固定标量 RCS，
不覆盖随姿态变化的扩展目标响应或场景规模的任意增长。

保留的 MATLAB R2025b CPU 旋转结果为 250.7 ms；WiTwin 最终 608.7 ms 仍约慢 2.43×。
本轮没有重新运行 MATLAB，其设备、精度、分数延迟滤波差异沿用原始对照报告的限定。
没有从这次优化得出“比商业仿真器普遍更快”或“所有复杂场景达到毫秒级”的结论。

另行读取原 MATLAB MAT 文件复核：旋转、加速、双散射点和静态场景的 WiTwin
优化前后 IQ 相对变化分别为 3.26e-8、3.14e-8、4.82e-8 和 0。
去除相同启动滤波保护样本后，优化旋转 IQ 与所保留 MATLAB IQ 的原始相对差约 2.34%；
该差异仍包含 MATLAB 分数延迟滤波模型，不能等同于真实测量误差。
详细指标保存在 `output/rotor-optimization/retained-matlab-comparison.json`。

## 验收与可重现性

原生 ABI 更新为 7：38 个操作符、14 个 AD 组。构建日志、定向测试、完整测试和静态门禁
保存在 `output/rotor-optimization/`，最终结果及哈希见本报告同名 JSON。

- 定向 GPU 测试：50 通过，包括任意 ADC 时间的独立复数公式/VJP/JVP、空路径、
  TDM、相关相位噪声、路径短暂出现、移动反射体、多站点反射的梯度。
- CPU quick：701 通过、850 跳过（CPU tier 跳过 CUDA 用例）、覆盖率 56%，所有 quick 门禁通过。
- 指定的 9 项静态门禁通过，Ruff 格式/检查和原生绑定清单通过。
- 第二轮完整 GPU：**1538 通过、12 跳过、1 失败**，没有缺失 Channel 导致的跳过。
  12 项跳过为 11 项缺少 SMPL 资产及 1 项外部 wheel 共存工作流。
- 唯一剩余失败为既有 Channel 反向耗时比门禁，**验收未全绿**。两轮完整运行测得 2.0495、
  0.7899，均超出原 `1 < ratio < 2` 条件；原测试单独复核得到 1.2168 并通过。
  无对应数值或 AD 失败，不能据此单次通过认定性能门禁稳定。

为排查测量顺序偏差，临时测试过均衡 AB/BA 顺序，三次得到 1.7024、2.2992、1.2568，
仍不稳定。因此撤回该实验改动，原测试和阈值完全保留，未用择优复测或放宽阈值宣布全绿。
测试退出后 `nvidia-smi` 记录 GPU 利用率 39–44%、WDDM、约 13100 MiB 显存占用，含 UnrealEditor
及其他桌面程序。此记录支持存在并发负载，但不能单独证明某个进程就是该门禁波动的原因。
性能门禁需要在可控 GPU 负载下进一步复验；未擅自结束用户进程或修改 GPU 时钟。
